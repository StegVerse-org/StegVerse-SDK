# StegVerse SDK 1.3.0

StegVerse SDK 1.3.0 is the post-1.2.0 successor source candidate for the processor-generic external-framework ingress and public governed-runtime distribution work.

This candidate includes:

- processor-generic `stegverse.ingress-manifest.v1` handling that keeps source-native payload class separate from processing capability and runtime route;
- evaluator preregistration retained outside the governance decision input;
- `stegverse external-run` preparation/execution flow with caller-selected return projection, canonical `manifest_receipt_id`, replay, and reconstruction;
- public governed-test distribution identities `stegverse-stegcore==0.3.0` and `stegverse-master-records==0.2.0` while preserving the StegCore import namespace `stegcore`;
- an anonymous governed-runtime installation and ELAN Test 1 end-to-end gate that remains fail-closed until the exact public runtime distributions are authentically published.

Release boundary:

- `v1.2.0` remains an immutable prior frozen release identity and must not be moved or retargeted;
- this file does not create `v1.3.0`, a GitHub Release, PyPI publication, runtime activation, or TV/TVC release authorization;
- the source candidate must be frozen only after exact-head validation, then publication must remain subject to the canonical TV/TVC release gate and verified Trusted Publisher provenance.
