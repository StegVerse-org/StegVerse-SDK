## Separate first-party corrected description

The SDK supports construction and validation of processor-generic ingress manifests. A caller declares the desired processing capability and a route, and the validator checks the envelope, identity and payload or commitment. The README describes a complete-manifest SOUTH lifecycle that includes any required Publisher presentation and eventual egress/far-side transitions. **None of those source facts proves that a given request was admitted, executed, stored or reconstructed.** A live result requires the corresponding authorized, request-bound receipt chain and Master Records readback.
